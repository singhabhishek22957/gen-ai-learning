# GenAI Learning 🚀

A hands-on repository documenting my journey of learning **Generative AI (GenAI)** using Python, LangChain, Ollama, and Large Language Models (LLMs).

This repository contains code examples, experiments, notes, and practical implementations to understand GenAI concepts step by step.

## 📚 Topics Covered

- **Python for GenAI** — Fundamentals and practical examples
- **Large Language Models (LLMs)** — Model inference and prompt-based interactions
- **LangChain** — Models, prompts, chains, output parsers, and runnable components
